# Bookwise

Bookwise is a reading journal and book discovery platform for readers who want to track books, write reflections, and share recommendations.

This repository currently contains **project information and a starter page only**. Application source code has not been added yet.

## Planned Product Scope

- Personal reading journal
- Book lists and reading status tracking
- Review and annotation sharing
- Personalized book recommendations
