Bookwise 📖✨

An intelligent macOS and iPadOS reading companion that transforms technical books, study guides, and PDFs into an interactive learning experience.

It extracts page text, generates insights with Apple Intelligence (plus local fallback), and provides synchronized read-aloud playback.

Status: README and info page are included. Source code is not included yet.

Core Capabilities

  • Multi-mode insights: Tutor Lesson, Key Summary, Deep Dive, and Takeaways.
  • Interactive document chat with current-page and full-document scope.
  • Prompt customization at both document and global levels.
  • Real-time synchronized narration with word highlighting.
  • Vision OCR for charts, diagrams, and scanned/image-only pages.

Build Requirements (Planned)

  • macOS 14+ (Sonoma)
  • Xcode 26 Beta
  • Swift 6+
